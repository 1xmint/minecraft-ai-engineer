  feasibility and verified paired releases.

  schematic reuse, measured optimization and concurrent independent builders.

Natural addressed conversation is primary; commands are fallback. Server-owned
identity, project permissions, current connections, reservations and execution
remain mandatory. Keep intended, observed and verified state separate. Imports,
remembered claims and loaded records never grant ownership, authority or a pass.

creative fallback, automatic compensation or silent overwriting of player edits.

credential sharing, separately billed API or API keys. Joining grants no model
